# 截图取景框（dsh-easysnap-plugin）

给 DeepSeek Harness 用的常驻桌面取景框。它解决的是一个很具体的麻烦：**你正在看的那个窗口，往往没法直接贴进对话**。

## 它解决的问题

用 DSH 做开发时，经常需要让模型看屏幕上的东西——一个报错弹窗、一段 Godot 场景、一张 Blender 预览。常规做法是：

1. `Win + Shift + S` 截一块 → 存成文件 → 再把文件拖进对话；
2. 或者截图后按 `Ctrl + V` 粘贴（能成，但每张都要重新框一次）。

dsh-easysnap-plugin 把这些步骤压缩成**一次点击**：框一直摆在你要盯的区域上，改完东西点一下 `Snap`，图就进对话了。

## 交互

| 操作 | 行为 |
|---|---|
| 拖底栏（含提示文字） | 移动整个取景框 |
| 拖上 / 左 / 右边框 | 单向拉伸（光标变双箭头） |
| 拖左上 / 右上角 | 斜向缩放 |
| `Snap` / `Enter` | 抓框内画面，插入对话，**框不关** |
| `X` / `Esc` | 关闭取景框，页面按钮立刻恢复 |

底边刻意**不参与拉伸**：它和底栏的拖动区重叠，做了拉伸反而会让用户点不到拖动条。

## 实现要点

- **不能纯前端**：DSH 的 Electron 显式禁用了 `getDisplayMedia`（`setDisplayMediaRequestHandler` 回调空对象），所以浏览器端截屏会永久挂起。插件改由宿主 spawn 一个 PowerShell/WinForms 进程拍屏。
- **DPI-aware**：进程启动时声明 `SetProcessDpiAwarenessContext`，否则在 125% 缩放的屏幕上窗口逻辑坐标与物理像素不一致，截出来的区域会整体偏移。
- **窗口 Region 抠洞**：把取景区从窗口区域里真正挖掉（而不是用 `TransparencyKey` 颜色键），这样框内透明且**点击穿透**，框外边框仍然可点。
- **保持置顶**：每 300ms 用 `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)` 重新压到最前——Windows 在多个置顶窗口之间按激活顺序排序，点一下聊天窗口就会把取景框压下去。
- **去重**：`mtimeMs` 是浮点，页面传来的 `since` 是整数，直接比较会让同一张图被反复判定为"新图"。两端都取整后比较，并返回 `x-shot-ts` 让页面二次去重。
- **状态自愈**：点 `X` 关框但没拍图时，`/state` 会立刻告诉页面 `alive:false`，按钮不会卡在忙碌态。

## 边界

- Windows only；
- 框内若被其他窗口遮挡，抓到的是遮挡物（屏幕抓取的本质）；
- 取景框是独立进程，DSH 退出不会带走它；
- 多显示器只按主屏居中，跨屏需手动拖。

## 后续可以做的

- 记住上次的位置和大小；
- 全局热键唤出 / 隐藏；
- 框内标注（箭头 / 矩形 / 文字）；
- 多张自动拼成长图再发。
